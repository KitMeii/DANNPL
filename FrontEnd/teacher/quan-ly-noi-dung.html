Import từ file — PDF, Word, Text KHUYÊN DÙNG

Kéo thả 1 hay nhiều file vào đây — hệ thống tự nhận dạng loại file. PDF: AI tự động trích xuất câu hỏi nếu không tìm thấy định dạng "Câu X:" có sẵn. Word/Text: cần định dạng "Câu X: ..." → A./B./C./D. → ĐÁP ÁN: X, các lựa chọn phải gõ tay thành chữ, không dùng danh sách tự động (bullet/numbering) của Word.

File này dùng để làm gì?

📋 File đã có sẵn câu hỏi soạn theo mẫu
Đọc trực tiếp câu hỏi có sẵn trong file (định dạng "Câu X:" → A./B./C./D. → ĐÁP ÁN: X) — giữ nguyên luồng import hiện tại.
🤖 Dùng AI đọc nội dung, tự sinh câu hỏi
Dùng khi file là tài liệu/bài giảng (chưa có sẵn câu hỏi) — AI đọc và soạn câu hỏi để bạn duyệt/sửa trước khi lưu.
